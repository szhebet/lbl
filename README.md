# Домашняя библиотека
Приложение для управления библиотекой электронных книг.

Классический README можно почитать по ссылке: [Readme](./Classic_README.md)

Здесь описана история создания и чем данный проект может быть полезен.

**Внимание!!!** 
**90% кода в данном проекте написано с помощью ИИ.**

**При этом проект проверен, лишнего не делает, полезное - делает.**

**На всякий случай запускайте в docker и делайте резервные копии.**

## История

Наверное у каждого ИТ специалиста есть проект, до которого не доходят руки, но которым хотелось бы заняться когда-нибудь потом, когда будет свободное время.
С приходом в нашу жизнь ИИ все изменилось, код сал писаться самостоятельно и до проектов не первого приоритета начали доходить руки. 

У меня таким проектом была идея домашней библиотеки: за последние годы скопилось некоторое количество электронных книг, прочитанных, или отложенных на потом, которые все хранятся в папке на жестком диске, с названием "прочитать когда-нибудь". Много дублей, много прочитанных или забытых.
Все книги в разных форматах (от doc файлов версии Word 95 года до современных fb2 и epub)

Основной идеей этого проекта было "как-то" привести все в порядок, удалить дубликаты, разобраться, что прочитано, что нет.

## Возможности
1. **Массовый импорт** книг из каталога с разбивкой по авторам, названиям, жанрам
2. **Автоматическое определение автора и названия.** Не во всех форматах автор и название указывается в метаданных. Если автора или названия нет - определяем его с помощью LLM. Можно использовать любую модель с openAI Compatible протоколом, указав модель в config.toml или .env. В проекте использовалась phi4 mini (т.к. быстрая и маленькая) + ollama (т.к. просто).  
3. **Пользователи** - 4 роли, у каждого пользователя свой профиль.
4. Т.к. хотелось доступ к библиотеке из интернета, то **аутентификация по логину и паролю + JWT-токены**
5. И поскольку все писала LLM, не факт что код очень безопасен, на всякий случай - возможность закрыть доступ клиентским сертификатом на уровне **nginx**.
6. Отметки о прочтении - для каждого пользователя свои, чтобы не забыть, что прочитал.
7. **Списки чтения** - чтобы не забыть, что нужно прочитать
8. **APK приложение** с клиентским сертификатом чтобы можно было скачать книгу или отметить прочтение на телефоне, когда в дороге
9. У вас наверняка были ситуации, когда, например летишь в самолете, тебе рекомендуют почитать книгу. Ты пытаешься ее запомнить и - забываешь. Чтобы такого не было - списки чтения работают офлайн с последующей синхронизацией после появления связи.
10. Возможность **запросить книгу у других пользователей** на сервере.
11. **Построение сети доверенных серверов** (федерации), поиск и обмен книгами с доверенными серверами.
12. Возможность запросить книгу у пользователей доверенных серверов.
13. Если детям в школе дали список литературы на чтение летом, то его тоже можно загрузить в списки чтения, с помощью LLM связать с книгами, которые есть в библиотеке, далее - отслеживать статус прочтения (когда-нибудь запишу видео, как это работает). 
14. И конечно, загрузка на ридер через локальный OPDS каталог.
15. Автоматическое обновление APK после пересборки проекта (CI пока не настроен, файлы APK и версий нужно раскладывать вручную, но на стороне APK-клиента все работает)
