# План безопасности для публикации сайта через nginx

## Найденные проблемы и приоритеты

### 🔴 Критические (исправлять немедленно)

| # | Проблема | Файл | Описание |
|---|----------|------|----------|
| 1 | **SQL-инъекция** через имена колонок | `main.go:1987-2004` | `updateBookExtended` принимает `map[string]interface{}` в `req.Work` и `req.Edition` и вставляет ключи напрямую в SQL без валидации. Злоумышленник может передать `{"password_hash = 'newpass' --": "x"}` |
| 2 | **Admin-роуты без аутентификации** | `main.go:528-543` | Все `/api/v1/admin/*` эндпоинты доступны без токена. Любой может создать/удалить пользователя, изменить пароль, удалить данные |
| 3 | **Path Traversal в import/directory** | `main.go:3266-3307` | `dirPath` из `c.PostForm("directory")` используется в `filepath.Walk()` — можно прочитать любую директорию сервера |
| 4 | **Path Traversal в import/upload** | `main.go:3069` | `fh.Filename` из multipart формы используется в `filepath.Join(tmpDir, fh.Filename)` — filename вида `../../etc/passwd` может выйти за пределы tmpDir |
| 5 | **JWT secret hardcoded** | `jwt.go:12` | `"your-secret-key-change-in-production"` — общеизвестный ключ, токены можно подделать |

## План исправлений

### Шаг 1: SQL-инъекция в updateBookExtended
- Заменить динамическое построение запроса с ключами из `map[string]interface{}` на строго типизированные поля с белым списком разрешённых колонок

### Шаг 2: Admin аутентификация
- Создать middleware `adminAuthMiddleware()`, проверяющий JWT и роль `admin`
- Применить ко всем `/api/v1/admin/*` роутам

### Шаг 3: Path traversal
- В `startImport()` проверять, что `dirPath` не содержит `..` и является абсолютным путём
- В `importUploadFiles()` санитизировать имя файла перед записью

### Шаг 4: JWT secret в конфиг
- Добавить `jwt_secret` в конфигурацию TOML
- Заменить глобальную переменную на загружаемое из конфига значение

### Шаг 5: User enumeration
- Возвращать одинаковую ошибку при login: "Неверное имя пользователя или пароль"

### Шаг 6: Лимиты на загрузку
- Добавить `MaxMultipartMemory` в Gin
- Лимит 100MB на книгу, 10MB на обложку

### Шаг 7: Error handling
- Заменить `err.Error()` в production-режиме на общие сообщения
- Логировать полную ошибку в server log, клиенту возвращать "Internal server error"

### Шаг 8: /debug/goroutines
- Убрать или сделать доступным только с ролью admin

### Шаг 9: Очистка temp при ошибках
- Добавить `defer os.RemoveAll(tmpDir)` при ошибках в importUploadFiles
