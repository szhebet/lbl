1. Добавь таблицу связей suggestion.

Поля таблицы:
read_list
Edition
User
Hidden


в данной таблице будут храниться связи с предложенными пользователями книгами.

2. На странице администрирования добавь вкладку "Запросы", вкладка доступна пользователям с ролью amin и editor

3. На вкладке "Запросы" выводятся поля "Название книги", "Автор книги", Пользователь из таблицы read_list только для записей, где поле LookingFor не равно "Нет" и нет записей в таблице suggestion, где ID равен ID объекта read_list и пользователь равен текущему пользователю от имени которого просматривается список.

4. Операции в таблице: "Предложить книгу", "Загрузить", "Скрыть".

5. Фильтр на странице: Пользователь, Название, Автор, Скрытые (Значения: Все, Да, Нет. Значение по умолчанию - Нет). Если в фильтре установлено "Все", то в список выводятся все записи без учета фильтрации: "и нет записей в таблице suggestion, где ID равен ID объекта read_list и пользователь равен текущему пользователю от имени которого просматривается список". Если устанавливается значение "Да", то выводятся только записи для которых есть записи в таблице suggestion, где ID равен ID объекта read_list и пользователь равен текущему пользователю от имени которого просматривается список.

6. При нажатии на кнопку "предложить книгу" открывается форма создания записи таблицы suggestion. Поле read_list - недоступно для редактирования и заполнено по умолчанию (id записи read_list, на которой нажали кнопку). Поле Edition - заполняется из выпадающего списка книг (по аналогии как это сделано на форме редактирования списка для чтения read_list). Поле пользователь - скрыто, заполняется автоматически (текущий пользователь). Поле "Hidden" - по умолчанию заполняется "Да". 

Если для данной записи read_list уже были другие записи таблицы suggestion для текущего пользователя, то на форме создания аналогичный раздел дублируется с предзаполнением и возможностью редактирования или удаления раздела. Если пользователь нажимает удалить раздел и сохраняет форму, то соответствующая запись из таблицы suggestion удаляется.

7. При нажатии кнопки "Скрыть" - создается запись в таблице suggestion, с read_list = текущей записи, Edition = пусто, User = текущий пользователь, Hidden = "Да". После этого список обновляется.

8. При нажатии кнопки "Загрузить" - открывается форма Импорта одного файла (копия раздела "Загрузить файл книги" с вкладки "Импорт") с соответствующим функционалом выбора файла и нажатием кноки "Загрузить" и "Отмена". После нажатия кнопки "Загрузить" - выполняется синхронная загрузка книги и связывание с ней соответсвтующей записи read_list через таблицу связей suggestion.
Если возникла ошибка при загрузке книги, то текст ошибки выводится пользователю, но записей в БД не создается.
